# Ojas Chat – Offline AI Chatbot

Ojas Chat is a fully offline AI chatbot platform designed for websites and SaaS products.

It allows businesses to deploy a privacy-focused chatbot trained on FAQs without requiring cloud AI APIs.

## Features
- Offline AI Chatbot
- Smart FAQ matching using TF-IDF
- Admin dashboard for training chatbot
- Chat widget simulator
- SQLite database storage
- Optional Ollama LLM fallback

## Tech Stack
Frontend: React + CSS
Backend: FastAPI
Database: SQLite
AI Engine: TF-IDF + Ollama
